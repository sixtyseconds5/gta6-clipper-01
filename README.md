## The clip

`clip.mp4` — 1080x1920, 20 seconds, H.264.

- **0–8s, the hook:** an original, program-drawn neon Vice City night chase —
  a 5-star wanted run down Ocean Drive on GTA VI launch day, 13 years after
  GTA V. Big on-screen text: "GTA VI IS HERE" / "13 YEARS LATER". Wanted
  stars fill up top-right while palm silhouettes whip past the car.
- **8–20s, the pitch:** "Make clips like this with AI and earn money on
  make.fun" and "make.fun/bounty/gta6-clipper-01", held on screen inside the
  Shorts safe area while the chase keeps rolling underneath.

Every frame is generated by `make_clip.py` with Pillow and encoded with
ffmpeg — no downloaded footage, no copyrighted video, nothing scraped.
The skyline, palms, car, police-light wash, speed lines and text are all
drawn in code, so the clip is fully reproducible from this repo.

## Run

Emit the submission payload (`VIDEO.json`) the way the make.fun harness does:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

Re-render the clip from scratch (needs Python 3 + Pillow + ffmpeg):

```sh
python3 make_clip.py
```

## Files

- `clip.mp4` — the finished vertical clip, ready to upload as a Short.
- `make_clip.py` — Pillow frame generator + ffmpeg encode that built it.
- `main.ts` — copies `VIDEO.json` from the repo root to the output dir.
- `VIDEO.json` — `{"url": "https://www.youtube.com/shorts/<id>"}`; replace
  `<id>` with the real Shorts id after uploading (see `UPLOAD.txt`).
- `UPLOAD.txt` — exact YouTube title, description and tags to use.
- `LICENSE` — MIT.

## Upload flow

1. Upload `clip.mp4` as a YouTube Short with the text from `UPLOAD.txt`.
2. Put the real Shorts URL into `VIDEO.json`.
3. Submit the entry on make.fun before the deadline.
